# Sales Agent Skills

Plain-language instructions that help salespeople set up their own AI assistant. Each skill works as an installed skill, or by pasting its link into an AI chat. From [MKTNG](https://mktng.co).

## Skills

| Skill | What it does |
| --- | --- |
| [grill-me-sales](grill-me-sales/SKILL.md) | Starts from your company website, interviews you in short rounds about how you sell, and writes a one-page context document you approve. |

## Use it in any AI chat

Copy this into a new chat in Grok, ChatGPT or Claude, and add anything you already have at the end:

```
Open this link and follow the interview instructions in it exactly:
https://raw.githubusercontent.com/MKTNGco/sales-agent-skills/main/grill-me-sales/SKILL.md

Start by asking who I am. Here's anything I already have:
```
